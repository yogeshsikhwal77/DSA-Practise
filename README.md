## 👋 About This Repository

Welcome to my **DSA Practice Repository**! 🚀

This repository contains my **Data Structures & Algorithms practice in C++**, following the **Striver's A2Z DSA Sheet** as my primary roadmap.

I am solving problems topic by topic and pushing my solutions to GitHub as I progress. The main purpose of this repository is to develop strong problem-solving skills, understand important DSA patterns, improve my C++ programming, and build consistency through regular practice.

This repository is not intended to be just a collection of code. It represents my **learning journey** — including the concepts I learn, problems I solve, mistakes I make, and the progress I achieve over time.

> 💡 **The goal is not to memorize solutions. The goal is to understand the pattern and learn how to solve problems independently.**
